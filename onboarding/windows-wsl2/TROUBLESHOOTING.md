# WSL Troubleshooting

## Проблема: проект открыт из `C:` и всё тормозит

Решение:

- перенеси рабочую папку в `~/work/...` внутри Ubuntu;
- открой проект заново через Remote - WSL.

## Проблема: `docker` не найден

Решение:

- запусти Docker Desktop;
- включи WSL integration;
- перезапусти терминал WSL.

## Проблема: `npx supabase start` не запускается

Проверь:

- установлен ли Node.js;
- доступен ли Docker из WSL;
- выполнен ли `npm install`.

## Проблема: `code .` не открывает VS Code

Решение:

- открой VS Code вручную;
- используй Open Folder in WSL;
- затем можно повторить `code .` из нового терминала.
